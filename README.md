# 花朝靈院 Bloomveil

東方幻想魔法學院題材的手機直向半文字戀愛養成遊戲。玩家從邊陲小鎮雲溪鎮出發，進入花朝靈院，在學業、能力、人際與「玉蘭院」之謎之間取捨。

目前內容：序章＋第一章「無名花影」（一年級第 1–28 日）。

## 怎樣玩

遊戲是純網頁，不需要安裝任何工具。

- **在電腦上試玩**：因為瀏覽器限制，直接雙擊 `index.html` 可能讀不到圖片。可以在資料夾裡執行 `python3 -m http.server`，再打開 `http://localhost:8000`。
- **放上網**：在 GitHub repo 的 **Settings → Pages** 選擇 `main` 分支、根目錄 `/`，幾分鐘後就會有網址。（私人 repo 需要付費方案才可以開 Pages。）
- **加到手機主畫面**：用手機瀏覽器打開網址，選「加入主畫面」，會以全螢幕 App 形式開啟，並顯示木蘭花圖示。

## 檔案結構

| 檔案 | 內容 |
| --- | --- |
| `index.html` | 入口：讀取最新版本號，再跳到 `v/<版本>/`（由 `tools/build_repo.py` 產生） |
| `v/<版本>/index.html` | 遊戲本體：介面、引擎、存檔系統、載入畫面（每個版本一個新網址，手機不會讀到舊快取） |
| `version.json` | 目前版本號 |
| `tools/build_repo.py` | 發佈工具：產生入口、版本頁與 `version.json` |
| `story.js` | 全部劇本與遊戲資料：角色、羈絆事件、主線、地點、場景對應、表情、CG |
| `audio.js` | 即時生成的東方魔法風音樂與聲效（不使用音檔） |
| `manifest.json` | 加到主畫面時的 App 名稱、顏色與圖示 |
| `icons/` | App 圖示（32、180、192、512 及 maskable 版本） |
| `img/` | 遊戲用圖片（已壓縮） |

| 檔名 | 用途 |

| `title.jpg` | 載入畫面主視覺 |

## 怎樣修改劇本

所有對白都在 `story.js`，不需要改 `index.html`。

- 對白格式：`['說話者', '文字', '表情']`。說話者可以是 `''`（旁白）、`'me'`（主角）、角色 id（如 `'pei'`），或 `'npc:名字'`。
- 文字裡的 `{n}` 會換成主角名字，`{弟妹}` 會依性別換成「學弟」或「學妹」。
- 表情：`happy`（大笑）、`smile`（淺笑）、`shy`、`angry`、`cold`／`serious`（皺眉）、`sad`。
- 指令：`['#scene', 地點]`、`['#choice', 提示, [選項]]`、`['#quest', 編號]`、`['#note', 日記]`、`['#gain', 能力, 數值]`、`['#aff', 角色, 數值]`。
- 新增場景圖：把圖放進 `img/`，再在 `story.js` 的 `SCENE_IMG` 登記地點名稱。

## 存檔

- 每個時段開始時自動存檔；另有三個手動存檔位。
- 存檔保存在玩家自己的瀏覽器裡。換裝置時，可以在遊戲內「存」頁面匯出／匯入存檔碼。
